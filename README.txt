Stream DZ (Android TV) - النسخة الأصلية Compose

1) أنشئ مستودعاً جديداً على GitHub وارفع كل ملفات هذا المجلد كما هي (بدون مجلدات).
2) Add file > Create new file واكتب الاسم:   .github/workflows/build.yml
   والصق محتوى الملف build.yml.txt ثم Commit.
3) افتح Actions وانتظر العلامة الخضراء، ثم حمّل StreamTV-apk من Artifacts.
